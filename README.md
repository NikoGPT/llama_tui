# Llama TUI Chat 🦙

Простой терминальный чат для запуска любых нейронок (LLM) локально. Работает через движок `llama.cpp`.

## Что это умеет:
- Полностью локальный запуск, никакого интернета.
- Помнит контекст переписки (не забывает, о чем говорили раньше).
- Поддерживает любую модель в формате `.gguf` (Llama, Qwen, Mistral и др.).
- Сам запускает и выключает сервер нейронки.

## Как запустить:
1. Качаешь бинарники `llama.cpp` для Windows.
2. Кидаешь `llama-server.exe` и все `.dll` файлы в папку `bin`.
3. Кидаешь любую модель `.gguf` в папку `models`.
4. Запускаешь `start.bat`.

Батник сам создаст окружение и доставит нужные библиотеки (`textual`, `requests`).

## Управление:
- **Ctrl + Enter** (или **Ctrl + J**) — Отправить сообщение.
- **Ctrl + L** — Очистить чат и сбросить память нейронки.
- **Ctrl + Q** — Выход (программа сама очистит видеопамять).

## Структура:
- _main_.py — запуск и логика.
- model_chat.py — общение с сервером.
- ui.py — интерфейс.
- search.py — поиск моделей.
